Compared to the rest of these projects, QR Code CLI was a much smaller and less ambitious project, but it's still something I'm proud of. It's a CLI written in Python that allows you to generate QR Codes up to version 6, which isn't all too impressive, but I actually wrote it from the ground up. That both means that I didn't just import a QR Code library and that I didn't vibecode a single line of code.

When I made this project, I had just finished self-studying the Neetcode DSA course, and I wanted to test that my DSA knowledge was actually applicable. While the logic behind understanding how QR codes themselves work was pretty difficult, I actually found that the coding itself wasn't too hard, and I ended up using a lot of DSA principles that I didn't expect to.
