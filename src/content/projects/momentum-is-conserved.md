Momentum is Conserved was my first game and passion project. It's a 3D platformer that uses the ability to store and release momentum as the main movement mechanic, and the movement actually ends up being pretty satisfying.

I didn't know how to use Blender back then so the game doesn't look pretty, and the music is AI generated, but for my abilities at the time, I'm still proud of how the game turned out. Also I didn't vibecode it if you couldn't tell!
